วิธีนำเว็บขึ้นออนไลน์แบบฟรี

ตัวเลือกที่แนะนำ: GitHub Pages
1) สมัคร/เข้าสู่ระบบ GitHub
2) สร้าง Repository ใหม่ เช่น wat-matchimawas-guide
3) อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (index.html + รูป .jpeg)
4) เข้า Settings > Pages
5) เลือก Deploy from a branch
6) เลือก branch main และ folder /root
7) Save
8) รอให้ GitHub สร้างเว็บไซต์ แล้วจะได้ลิงก์ประมาณ:
   https://ชื่อผู้ใช้.github.io/wat-matchimawas-guide/

หลังได้ URL:
- นำ URL ไปสร้าง QR Code
- ใส่ QR ในคลิป
- ทดสอบเปิดเว็บจากมือถือและสแกน QR ก่อนส่งงาน

หมายเหตุ:
- เว็บไซต์นี้เป็นไฟล์ HTML/CSS สำเร็จรูป ไม่ต้องซื้อโฮสติ้ง
- ภาพที่ให้มาจากผู้ใช้ถูกใส่ไว้ในแพ็กเกจแล้ว
